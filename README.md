# Documentation

This is the website of Joschka Hüllmann using Jekyll and Bundler.

## How to build

If you do not have ruby: `sudo apt install ruby ruby-dev build-essentials` (or use [rbenv](https://github.com/rbenv/rbenv)). Last time I checked Debian distributed ruby-3.3 which is compatible with GitHub pages and Jekyll.

1. Start by [installing Bundler](http://bundler.io) `gem install bundler`
2. Set bundle path `bundle config set path ~/.local/share/gem/` (default last time I checked)
3. Clone the repository
4. Then run `bundle install` to get [Jekyll](http://jekyllrb.com) and all the dependencies.
5. Run the Jekyll server with `bundle exec jekyll serve`
6. Go to `http://localhost:4000`
